## 🖼️ Tempat Menambah Gambar

Untuk menambah gambar, silakan:

1. **Foto Tim Psikolog:**
   - Letakkan file di: `assets/images/psikolog.jpg`
   - Rekomendasi ukuran: 600x400px

2. **Avatar Testimoni:**
   - Letakkan file di: `assets/images/avatar1.jpg` sampai `avatar6.jpg`
   - Rekomendasi ukuran: 100x100px (circular)

3. **Gambar Lainnya:**
   - Buat folder sesuai kebutuhan di dalam `assets/images/`

## 🔧 Cara Menggunakan

1. **Buka di browser:**
   - Buka file `index.html` di browser favorit Anda

2. **Sesuaikan konten:**
   - Edit teks di `index.html` sesuai kebutuhan
   - Ganti URL Google Maps sesuai lokasi bisnis Anda
   - Update nomor telepon, email, dan jam operasional

3. **Tambah gambar:**
   - Buat folder `assets/images/` jika belum ada
   - Upload gambar sesuai path yang sudah ditentukan

4. **Customize warna:**
   - Edit CSS variables di `assets/css/style.css`
   - Ubah nilai di `:root { --primary-color: #1abc9c; }` dll
